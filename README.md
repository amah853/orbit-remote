# Orbit Remote

Orbit is a browser-based remote desktop host for this Windows PC. Once connected, the page is only the remote desktop: no toolbar, status badges, or other stream UI.

## Performance

- 60 FPS H.264 stream generated by the AMD GPU
- Ultra-low-latency encoder mode with no B-frames
- 24 Mbps on mobile and 32 Mbps on normal desktop connections
- Windows itself automatically switches to the closest display mode for the client device
- Stream resolution follows that new desktop shape, with a sharp 1920-pixel Auto cap and up to 2560 pixels in manual modes
- Hardware decoding in browsers that support WebCodecs
- Automatic JPEG compatibility mode for older browsers
- Decoder acknowledgments and capture backpressure: the host pauses after at most 12 unprocessed frames
- Round-trip delay monitoring that discards and reconnects a stale video socket
- Adaptive bitrate and Auto-resolution scaling when a phone cannot sustain the selected rate

## Start the host

```powershell
npm install
npm start
```

Open `http://127.0.0.1:4173` on this PC. Show the access code at any time with:

```powershell
npm run code
```

## Connect from any browser

Run:

```powershell
npm run enable-anywhere
```

The first run downloads Cloudflare's official tunnel helper. Open the printed `https://...trycloudflare.com` address on a phone, tablet, or computer. The client device does not need an app or browser extension. Enter the private Orbit access code and the desktop will request fullscreen immediately.

While connected, tap the invisible top-right corner or press `Ctrl+Shift+S` to open stream settings. You can select Auto, 1280×720, 1440×900, 1920×1080, 2560×1440, or the native 3440×1440 desktop, and set a bitrate limit from 4 to 50 Mbps. Keep **Prevent stream delay** enabled unless you specifically need a fixed bitrate. Windows returns to its original 3440×1440 at 144 Hz after the final remote client disconnects.

The generated public address exists while the tunnel process is running and can change after it restarts. Orbit still requires the private access code and rate-limits failed logins.

## Automatic host startup

```powershell
npm run install-startup
```

The host must run in the signed-in Windows desktop session so it can capture the screen and accept input.

## Limitations

- Browsers only allow true fullscreen after a user gesture. Orbit requests it when Connect is pressed and again on the first desktop tap.
- The PC must be powered on, awake, signed in, and online.
- Windows secure screens, UAC prompts, and Ctrl+Alt+Delete cannot be controlled by a normal desktop app.
- Protected video and some exclusive fullscreen games may appear blank.
